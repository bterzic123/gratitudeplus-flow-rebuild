# Growth Audit — Gratitude Plus

**Live:** https://bterzic123.github.io/gratitudeplus-flow-rebuild/

Five ranked ideas for the Gratitude Plus iOS onboarding and paywall, each rebuilt as a working screen in a clickable prototype that uses Gratitude Plus's own design: the cream page, serif headlines, pink option cards, time wheel, chart, plan cards and Free vs Premium table. Only the order changes. The prototype carries every screen of the first session, from the splash to the first entry — 29 in all, grouped into before and after the paywall.

| # | Idea | Potential outcome |
|:-:|:--|:--|
| 01 | Offer month-to-month ($10.99) when someone closes the paywall | ARPU +10–15% |
| 02 | Set up the account and Circle after the paywall | CR +8% · ARPU +17% |
| 03 | Name their goal on the paywall | CR +15–20% |
| 04 | Ask for tracking and notifications after the paywall | CR +10–15% |
| 05 | Read their answers back before the price | CR +10–15% |

Open the prototype straight away: https://bterzic123.github.io/gratitudeplus-flow-rebuild/?open=proto

**Grounding.** Every price, rating, quote and feature line comes from Gratitude Plus's own App Store listing, website and in-app screens.

*Impact ranges are Adapty's expected effect from teardowns and A/B tests across subscription apps — not measured lift for Gratitude Plus.*
